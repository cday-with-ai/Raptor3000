# Piece sets

Copied verbatim from chessascent.app (Carson's own app,
`chessascent-app-front-end/assets/pieces/`), which in turn carries them
from the lichess piece-set collection (github.com/lichess-org/lila,
`public/piece/`). They are NOT covered by this repository's MIT license —
each set keeps its own:

- **cburnett** — Colin M.L. Burnett, GPLv2+ (the lichess/Wikipedia set).
  This is the app's default.
- **alpha** — Eric Bentzen, free for personal use ("Alpha" font pieces).
- **leipzig** — Armando Hernandez Marroquin, GPL.
- **cardinal** — sadsnake1, CC BY-NC-SA 4.0.
- **mpchess** — Maxime Chupin, GPLv3+.
- **vlgi** (*Very Little Gravitas Indeed*) — original, MIT. Soft,
  inflated Staunton with a thick outline: lobed king crown, ball-and-slit
  bishop on a splayed foot, banded skirts on the royalty only. Named
  after an Iain M. Banks Culture ship.

  Four siblings — `ocisly`, `jrti`, `asog`, `subtlety` — were removed on
  2026-08-19 (Carson: "the only grok set he added that was worth a damn
  is Very Little Gravitas Indeed"). Every retired id migrates to `vlgi`
  in `RENAMED_PIECE_SETS`, so nobody's stored choice silently resets.

  Its knight was cburnett's — see the note under `talon` — and was
  replaced the same day by one drawn in vlgi's own language:
  `piece-sets/vlgi-knight.py`. One path from ear to base the way the
  pawn is one path, a bell foot with a waist, and no bands, because in
  this set only the king and queen wear them.

If distribution terms ever matter beyond personal use, re-check each
license upstream (lichess documents them in `COPYING.md` / their piece
set credits) before shipping these files anywhere.
- **lathe** — original, MIT. Drawn 2026-08-19 for a brief of "different
  from everything we have yet, Staunton, elegant, and beats Talon". The
  roster already had cburnett's drawn line, Talon's carved facets and
  VLGI's inflated softness, so this is the third language and the one a
  real Staunton set is actually made in: **turned on a lathe**. Every
  piece below the head is a spun form and every piece carries the same
  three fine grooves the turner's tool leaves in the collar — nothing
  else on the board has them, and at 25px they are what you recognise it
  by. Slimmer, taller, and a 1.15 outline against the roster's 1.5.
  Generated by `piece-sets/lathe.py`; edit the generator, not the SVGs.

- **talon** — original, MIT. Drawn for this repo on 2026-08-19, not
  derived from any set above: a carved-wood Staunton on a two-step
  plinth, with a collar seam shared by all six pieces. Generated by
  `piece-sets/talon.py`; edit the generator, not the SVGs.

  A note on provenance, since it is the reason this set exists. The five
  "original" sets above have **byte-identical knights**, and all five are
  cburnett's knight with every coordinate nudged by at most 0.4 units in
  a 45-unit box (mean 0.10, 43 of 112 numbers untouched, path topology
  the same command for command). The other five pieces in each really
  are redrawn. So the MIT claim on those sets is at best unverified for
  the knight, which is a derivative of a GPLv2+ drawing. `talon` shares
  no path with anything.
